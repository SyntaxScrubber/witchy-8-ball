# Witch's Coven 8-Ball

A single-file, playable witchy Magic 8-Ball. Type a question, hit
"Consult Orb," and get a random witchy answer with an orb animation.

## How to run it

Open `magic8ball.html` in any browser. No build step, no server.

## What it shows

- HTML/CSS orb and stand, JavaScript random-answer picker
- Finished and playable as-is

## Note

It references a Kenia font file that isn't bundled, so it falls back
to a regular font. That doesn't break anything.
